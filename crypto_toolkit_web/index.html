Using the workbench

  1. Pick a direction

    Choose Encrypt if you have plaintext, or Decrypt if you have ciphertext to recover.

  2. Choose a cipher

    Each cipher has a different key format — check the hint text under the key field.

  3. Enter your key

    Some ciphers (Monoalphabetic, One-Time Pad) can auto-generate a valid random key for you with the "Auto" button.

  4. Type your text and run it

    The output, execution time, and character count appear immediately on the right.

  5. Inspect the process

    Expand "Show process" to see a character-by-character or block-by-block breakdown of exactly how the algorithm produced that output.

Frequently asked questions

Why did decryption give me gibberish?

You most likely used the wrong key, or a key in the wrong format for that cipher. Check the hint text — Rail Fence expects a number, Playfair expects a keyword, Hill expects exactly 4 letters.

What happens to spaces and punctuation?

Most ciphers here pass non-letter characters through unchanged. Playfair, Hill, Rail Fence and Columnar Transposition strip spaces since classical implementations operate on continuous letter streams.

Is this secure for real use?

No. Every cipher here is classical and broken by modern standards — they're for learning cryptographic principles, not protecting real secrets. Use AES or ChaCha20 for that.

Why is the Hill cipher key restricted?

A 2×2 Hill key matrix must be invertible modulo 26 (its determinant must share no common factor with 26) or decryption is mathematically impossible. Try a key like HILL or RSAX.

What does "Auto" do for the key?

For Monoalphabetic and One-Time Pad ciphers, it generates a valid random key of the right length so you can try the cipher immediately without picking one by hand.

Does anything leave my browser?

No. All encryption, decryption and file processing runs in JavaScript on this page — nothing is uploaded anywhere.
